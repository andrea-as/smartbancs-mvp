# Declaración de uso de inteligencia artificial

## Herramienta utilizada

Durante la preparación de este reto se utilizó un asistente de inteligencia
artificial para apoyar actividades de desarrollo y documentación. La revisión,
decisión técnica, ejecución local, validación y responsabilidad final de la
solución corresponden al candidato.

## Cómo se utilizó

- Proponer y revisar la estructura inicial del MVP.
- Apoyar la redacción y revisión de documentación técnica.
- Sugerir casos de prueba para concurrencia, ETL, Bancs y observabilidad.
- Ayudar a diagnosticar errores de configuración durante la ejecución local.
- Revisar que los entregables cubrieran los requisitos del reto.

## Componentes o actividades donde se aplicó

- API REST FastAPI y validaciones.
- Integración y normalización de eventos Bancs.
- Flujo asíncrono Redis + servicio de recomendaciones.
- Script ETL y dataset de prueba.
- Instrumentación de logs, métricas y trazas.
- Docker Compose, Kubernetes, Terraform, Ansible y CI.
- Documento de arquitectura, incidente y guía de demostración.

## Límites y controles

La IA no se utiliza como fuente autónoma de decisiones financieras reales. La
recomendación del MVP es determinista y demostrativa; no utiliza datos
personales reales ni una API externa de pago. El código fue ejecutado,
inspeccionado y ajustado localmente antes de incorporarse al repositorio.
